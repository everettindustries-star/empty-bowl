# The Empty Bowl

90-second hero film for **Who's A Good Boy Pet Accessories & Toys**.

## Concept

A rain-soaked crime thriller starring two bored pets — a scruffy terrier mix and a
short-haired grey tabby. Overlooked and under-stimulated, they stage a spree of
harmless household mischief. The "crime" is solved when a delivery of real toys arrives.

**Campaign line:** Good pets. Bad options.

## Tone rules

- Gritty, grounded urban noir. Rain, low light, dry narration.
- Animals do only plausible animal things. No talking, no cartoon behavior,
  no weapons, no distressed animals.
- Narrator: low, dry human crime-documentary voice. The animals never speak.

## How to use this repo

- `creative/script-v1.md` — the full script. Start here.
- `creative/storyboard-v1.json` — machine-readable shot list for tooling.
- `creative/shot-prompts/` — one AI video prompt per shot (shot-01 through shot-08).
- `brief/approved-claims.md` — fill in real product info before launch.
  Nothing ships with placeholder products.

## Versions

- `v1` = first draft. When the script changes substantially, save a new
  `script-v2.md` — never overwrite v1.
- Small fixes (typos, timing tweaks) can be edited in place with a clear commit message.
